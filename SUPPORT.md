# Getting help with Tracebound

Tracebound is a free app for Jira Cloud from Data Tools for All.

## First steps

1. Read the [setup and user guide](docs/setup.md).
2. Open Jira settings (cog) > Apps > **Tracebound setup**, type the project key and click **Check**.
   Each check says pass, warn or fail and what to do next, for example which project permission is
   missing.

## How to reach us

- **GitHub issues** (preferred): https://github.com/slizer138/tracebound/issues
  Please do not post customer data, issue text or your site address in a public issue.
- **Email:** datatoolsforall@gmail.com
  Use email for anything you do not want to post publicly, including security reports.

Helpful details to include: what you clicked, what you expected, what you saw (the error code or the
**Tracebound setup** check results), and whether the project is company-managed or team-managed.

## Response time

Support is best effort. We aim to reply within 3 business days. There is no phone or call support and
no guaranteed resolution time.

## Security issues

Report security problems to datatoolsforall@gmail.com with "Security" in the subject line. Please do
not open a public issue for them. Confirmed vulnerabilities are fixed within the timelines of
Atlassian's Marketplace Security Bug Fix Policy.

Tracebound makes no calls outside your Jira site, stores its data only in Atlassian's Forge storage
and asks for no passwords, tokens or API keys.
